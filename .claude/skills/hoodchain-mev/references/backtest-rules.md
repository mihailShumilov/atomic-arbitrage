# Правила бэктеста

Результат, нарушающий любое правило, считается недействительным, даже если он «очевидно показывает прибыль».

## 1. Никакого заглядывания в будущее

Признаки для решения по событию в `(B, i)` берутся только из данных строго до него: блоки `< B` и транзакции блока `B` с `tx_index < i`. Метки, посчитанные на всём датасете (например «этот кошелёк — создатель-ругер»), используются только если могли быть известны к моменту `B`.

## 2. Реалистичный вход

- Реактивная стратегия входит **не раньше блока B+1**: фид показывает уже собранный блок.
- Позиция внутри B+1 — **после всех покупок конкурентов**, реально попавших в B+1 по этому токену (консервативный режим по умолчанию). Оптимистичный режим (вход первым в B+1) допускается только как верхняя граница, рядом с консервативным, и с пометкой.
- Вход в блоке B (тот же блок, что триггер) реактивно невозможен. Моделировать его можно только для стратегий залпов, и тогда учитывать стоимость всех промахов.

## 3. Исполнение по состоянию пула, а не по наблюдаемой цене

Цена входа и выхода считается симуляцией свопа нашего размера по состоянию пула в точке исполнения (v3/v4: sqrtPrice + ликвидность по тикам; кривая: её формула), с учётом того, что предыдущие сделки в том же блоке уже сдвинули цену.

## 4. Все издержки

- Комиссия пула/launchpad'а с обеих сторон (у Pons v2 параметры свои у каждого запуска — читать из цепи, не хардкодить 1%).
- Ранний сбор/снайп-налог по возрасту токена в момент сделки.
- Газ входа и выхода по реальным чекам похожих транзакций (с L1-компонентом), по base fee того блока.
- Для стратегий с промахами (залпы, условные атомарные сделки) — газ всех откатившихся попыток.

## 5. Выход тоже конкурентный

Выход симулируется с тем же консерватизмом: конкуренты, продающие в том же или раньшем блоке, сдвигают цену против нас. Токен без ликвидности на выходе = потеря позиции целиком.

## 6. Никакой ошибки выжившего

В выборке все токены, включая руги, мёртвые и отфильтрованные позже. Нельзя строить выборку «токены, которые мы потом нашли в топе».

## 7. Обязательный отчёт

Каждый результат содержит:

- число эпизодов, доля выигрышных, средний выигрыш и проигрыш, EV на эпизод, итог;
- разбивку по неделям и по дням (максимальный дневной убыток);
- **итог без 10 лучших эпизодов**;
- бутстрап-интервал для EV (минимум 1000 ресэмплов по эпизодам);
- разбивку до/после 29.09.2026 (конец субсидии газа);
- долю эпизодов, затронутых незаполненными дырами фида (должна быть 0 или исключена);
- все допущения, отличные от консервативных по умолчанию.

## 8. Критерий «стратегия заслуживает следующего шага»

Положительный EV в консервативном режиме **и** без топ-10 эпизодов **и** нижняя граница бутстрап-интервала > 0 **и** не меньше 1 000 эпизодов **и** устойчивость по неделям (нет одной недели, делающей весь результат). Иначе — «преимущество не доказано», без смягчений.
