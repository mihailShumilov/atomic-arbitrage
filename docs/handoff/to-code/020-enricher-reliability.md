1. `FailKind` (enum) вместо поиска подстроки «429» в тексте ошибки; глобальная пауза — только по виду ошибки.

3. `--gaps`: при планировании проверять, что кусок влезает в бюджет `--max-calls`; иначе — ошибка конфигурации (не 75).
4. Гонка резерва бюджета (`rpc.rs` ~266) — без ложного раннего выхода 75; тест.
5. Коды выхода в одном модуле; `report()?` не подменяет 75/130.
6. `filled.tsv` читать мягко (`parse_ranges_file_lenient` из hood-core, WARN на битые строки — потеря строки безвредна, диапазон перекачается), `gaps.tsv` в enricher оставить строгим (architect-reviewer 019, Р9). Тест.
7. По возможности: API `Rpc::call` без вынужденных `unwrap` и двойного разбора; таймаут не булевым параметром.
