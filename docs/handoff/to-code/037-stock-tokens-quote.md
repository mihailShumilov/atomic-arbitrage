## Зачем
Михаил 2026-10-05 решил: токенизированные акции (GME, SPY, NVDA и др.) считать валютой котировки. Сейчас 1 514 v4-свопов против них пропускаются (035): у пары нет котировки.

## Что сделать
1. contract-registrar: официальный список токенов акций Robinhood Chain (docs.robinhood.com, официальный репозиторий/деплойменты, Blockscout) — адрес, символ, decimals, источник. Сверить с токенами из `data/registry/tokens-035.tsv`, которые встречаются в пропущенных свопах. Похожие подделки — отдельно, `rejected`. Внести в `contracts.md` со статусом `observed` (+ ссылки и способ проверки), в отчёте — список кандидатов в `verified` для Михаила.
2. Ранг котировки: стейблкоин 1, ETH/WETH 2; акции — 3 (одинаковый для всех акций; пара «акция/акция» — котировка по меньшему адресу, детерминированно, описать в `data-model.md`). Если `pools.rs` требует изменения правила сравнения — изменить с тестом.
3. Обновить `data/registry/tokens-035*.tsv` (`quote_rank` = 3 для акций) и прогнать `swaps_scan`: сколько строк добавилось, сколько осталось пропущенных и почему.
4. RPC: только если decimals не берутся из официального источника — `eth_call decimals()` через `PROVIDER_RPC_URL`, ≤ 100 вызовов, ключ не печатать.

## Что НЕ делать
- Ключ Alchemy нигде не печатать; сервер и фид не трогать; `verified` не ставить (это делает Михаил).

## Критерии приёмки
- Таблица токенов акций с источниками; числа `swaps_scan` до/после; data-auditor PASS (10 случайных новых строк сверены с сырыми логами).

## Формат отчёта
Сделано; источники; числа; кандидаты в `verified`; вопросы. `status: done` только после ревью, отдельный коммит.
