## Замечания (не блокируют)

- **Н1. В режиме `verified` строк 0, таблица не готова для выводов.** Без реестров пулов (на `data/` 1 464 v3-пула: у меня 1 462 с выведенными валютами плюс 2 без них; v4-пулов 3 027 — по отчёту, сам не пересчитывал) и decimals токенов `hood.swaps` пуста; в режиме `observed` — 3 строки. Любая аналитика по свопам до задачи о метаданных пулов должна идти по `PoolSwap` (аудит-TSV), а не по `hood.swaps`, либо явно помечаться `observed`.
- **Н2. Предположения, которые влияют на числа.**
  - WETH: 18 decimals — из исходника, в цепи не читалось.
  - `Swap.fee` v4 — полная комиссия (LP + протокол): одно наблюдение, 2500 → 2899.
  - Хуки v4: суммы — нога AMM.
  - `fee_quote` у продаж — приближение.

  Всё это честно помечено в `data-model.md`. До верификации `fee_quote` нельзя использовать как точную издержку. На пуле с комиссией 90 % (`0xadb0…d57c`) `fee_quote` ≈ 0.9 × `quote_amount`, это класс-ловушка и его надо фильтровать отдельно.
- **Н3. Порядок входов `swaps_scan`.** Пулы из `Initialize` действуют только на последующие файлы, а `hourly-*` перекрывает по номерам весь диапазон `data/blocks`. На `data/` это ни на что не влияет (п. 5). При подключении к загрузчику обходить блоки в цепном порядке по всем файлам сразу или хранить реестр между прогонами (п. 4 точки подключения в отчёте).
- **Н4. Площадка не сверяется с типом пула.** `PoolRegistry::parse_tsv` примет v3-пул с `venue = uni_v4` или `pons_v2_curve`. Простая проверка (`uni_v4`/`other` только для `PoolRef::V4`, `uni_v3`/`pons_v1`/`pools_trade` по реестру) убережёт от опечатки в TSV.
- **Н5. Перезаливка при смене реестра.** Ключ `(token, block_number, tx_index, log_index)` зависит от выбора `token`. Правило «удалить строки диапазона перед перезаливкой» записано, но загрузчиком пока не реализовано (подключения нет). Проверить в задаче подключения.
- **Н6. v4 без подходящего `Transfer`** (296 из 4 274 tx с одним свопом) — нативный ETH, ERC-6909 или хуки. Знаку это не противоречит, но для портретов трейдеров «что реально пришло на кошелёк» по v4 надо брать из `Transfer`/балансов, а не из `hood.swaps`.
