# 0002 — RPC-провайдер
status: proposed
date: 2026-09-30

## Контекст
Публичный RPC ограничен по частоте и не годится для истории и `--follow`. Нужен провайдер с Robinhood Chain. Известно: QuickNode поддерживает `robinhood-mainnet` (есть подключение в аккаунте; работает при включённом Tooling Access). Chainstack — кандидат, поддержка сети не проверена.

| Своя нода (см. 0001-B) | да | без лимитов | без лимитов | да | ~$500/мес на i4i.2xlarge |

## Критерии выбора
1. Цена за млн вызовов `eth_getBlockReceipts` (главная статья).
2. Лимит диапазона и результатов `eth_getLogs`.
3. `debug_traceBlock*` (граф финансирования, внутренние переводы ETH).
4. Реальный rps на тарифе.
5. WebSocket-подписки на блоки (резерв для фида).

## Рекомендация и почему
Нет данных — заполняется по отчёту 006. До этого: не покупать тарифы.
