# 0003 — Сервер для круглосуточной записи фида
status: proposed
date: 2026-09-30

## Контекст
Recorder должен работать 24/7. Сейчас кроме Mac Михаила машин нет. Требование: тестовые подключения к фиду (004, 005 и будущие) не делаются с IP продакшен-сервера — бан IP (~1 ч, со слов прежней сессии) оставит дыру в записи. Задержка на этапе записи не важна (важна полнота): дыры всё равно закрываются через RPC. Объём: ~2 ГБ/сутки сырого фида → ~60 ГБ/мес, плюс блоки из RPC.

## Варианты
| | Цена/мес | Диск | Надёжность | Минусы |
|---|---|---|---|---|
| A. Mac дома | 0 | локальный | низкая: сон, перезагрузки, перебои питания и связи | и тесты, и прод с одного IP |
| B. Недорогой VPS/dedicated в ЕС (Hetzner и подобные) | порядка $10–60 (уточнить) | 0.5–2 ТБ на dedicated | высокая | не в us-east-2; при фазе 2 всё равно переезд |
| C. AWS us-east-2, c7i.large/xlarge + gp3 | c7i.xlarge ~$130 + диск 500 ГБ ~$40 | EBS | высокая, рядом с секвенсором | дорого для фазы 1; трафик out платный |
| D. Dedicated в Колумбусе (площадка будущей ноды фазы 2) | ~$100–200 (уточнить) | большой | высокая, рядом с us-east-2 | раньше времени, если фаза 2 не случится |

## Критерии выбора
1. Полнота записи (аптайм, отсутствие банов от тестов).
2. Цена в фазе 1 (бюджет инфраструктуры ~$70–300/мес).
3. Диск на 3+ месяца (≥ 500 ГБ).
4. Переиспользование в фазе 2 (не обязательно).

## Рекомендация и почему
**B**: запись не требует близости к секвенсору, а дешёвый сервер с большим диском закрывает аптайм и разделяет IP (сервер — прод, Mac — тесты). Переезд в us-east-2/Колумбус — только если будет решение о фазе 2. Цены уточнит infra-ops отдельной задачей после 002 (юнит systemd готов).
