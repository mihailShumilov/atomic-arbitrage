# 0004 — Приоритет исследований: арбитраж и мем-импульс
status: proposed
date: 2026-09-30

## Контекст
Оба исследования используют один конвейер (блоки, tx, логи, свопы, метки). Различаются аналитикой: арбитраж требует чеков с откатами и позже симулятора на revm; мем-импульс — разметки розница/боты/создатели, графа финансирования (трассировки) и бэктеста выхода. Арбитраж — приоритет по этике (выравнивает цены) и по риску (нет позиции). Мем-импульс — игра с нулевой суммой против розницы, а главный вопрос (как лидеры попадают в блок N) может закрыть направление: если это привилегированный поток — не наш рынок.

## Варианты
| | Плюсы | Минусы |
|---|---|---|
| A. Параллельно | быстрее общий ответ | распыление; две разметки сразу; вдвое больше отчётов для скептика |
| B. Последовательно: арбитраж, потом импульс | фокус; симулятор — ядро бота | импульс ждёт 1–2 месяца |
| C. Конвейер общий, аналитика: арбитраж первым, от импульса только «дешёвый стоп-вопрос» (блок N: слепые залпы / общий триггер / привилегированный поток) | рано отсекает направление, почти без затрат | небольшое отвлечение |

## Критерии выбора
Этика; риск; стоимость времени Claude Code; ценность раннего «нет».

## Рекомендация и почему
**C**: конвейер общий по определению; основная аналитика — арбитраж; по импульсу — только вопрос 1 из `momentum-research.md` на тех же данных. Если ответ «привилегированный поток» — направление закрывается дёшево.
